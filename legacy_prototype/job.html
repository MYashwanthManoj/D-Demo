Associate Software Engineer

Infosys · Bengaluru, India

Full-time 0–2 yrs Hybrid ₹6–9 LPA

About the role

You will join a delivery team of eight to twelve engineers building and maintaining services for a banking client. The first three months are structured training: two weeks of classroom, then paired work on real tickets with a mentor reviewing everything you ship.

Write and review Java or Python services alongside a mentor for the first quarter

Pick up defects from the backlog and take them through to a tested fix

Write unit tests for everything you ship — this is checked at review

Join the daily stand-up and a fortnightly client demo

Document what you build in Confluence so the next person can pick it up

What they ask for

Required

  • B.Tech, B.E. or MCA, 2025 or 2026 batch
  • 60% or above through the degree
  • One programming language well — Java, Python or C++
  • Exposure to Git and a ticketing tool
  • Willing to work from Bengaluru three days a week

Nice to have

  • A project on GitHub you can talk through
  • Basic SQL
  • An internship of any length
